## 1. Verificação Local

Para testar como o `README.md` será renderizado antes de enviar para o GitHub:

1. Abra o arquivo `README.md` na raiz do repositório em seu editor (ex: VS Code ou IntelliJ IDEA).
2. Utilize a extensão nativa de pré-visualização Markdown (Markdown Preview).
3. Verifique se o tema do seu editor está configurado para o modo escuro (Dark Mode) para garantir que o contraste das cores néon e os ícones escuros funcionem corretamente.
